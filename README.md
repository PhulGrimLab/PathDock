# PathDock
개발자가 여러 프로젝트를 관리/전환 하는 도구입니다.

즐겨찾기 폴더 · 파일 탐색기 · 내장 터미널(PowerShell/명령 프롬프트)을 한 화면에 두고, 탐색기와 터미널의 현재 경로를
양방향(또는 단방향/끄기)으로 동기화합니다. C# / .NET 10 / WPF / MVVM. 화면은 **한국어/English**를 설정에서 바꿀 수 있습니다.

## 다운로드 (Download)

[**Releases**](https://github.com/PhulGrimLab/PathDock/releases)에서 `PathDock-v<버전>-win-x64.exe`(또는 `.zip`)를 받아 실행하면 됩니다.
.NET 런타임이 포함된 단일 파일이라 설치가 필요 없습니다(Windows 10 2004 이상 64비트. 개발과 확인은 Windows 11에서 했고, 다른 PC·Windows 10에서의 실행은 아직 확인하지 못했습니다).

- **관리자 권한으로 실행됩니다.** 실행할 때 UAC 확인 창이 뜹니다.
- 코드 서명이 없는 빌드는 처음 실행할 때 Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄울 수 있습니다("추가 정보 → 실행").
- 같은 릴리스의 `SHA256SUMS.txt`로 내려받은 파일을 확인할 수 있습니다.

*Download `PathDock-v<version>-win-x64.exe` (or the `.zip`) from Releases. It is a self-contained single file, so nothing needs to be installed.
It runs as administrator (a UAC prompt appears). Unsigned builds may trigger a SmartScreen warning.*

## 주요 기능
- **즐겨찾기** 10칸(클릭 한 번으로 이동, 우클릭으로 등록/이름 바꾸기/순서 이동/비우기), 드라이브 패널(사용량 막대)
- **탐색기**: 드라이브 · 조부모 · 부모 · 현재 폴더 열, 폴더 크기 집계(캐시), 정렬, 이름 검색,
  이름 변경/삭제(휴지통)/새 폴더/복사·이동·붙여넣기, 이미지 썸네일·PDF 첫 쪽·텍스트 미리보기 툴팁
- **터미널**: ConPTY 기반 PowerShell/명령 프롬프트, **여러 탭**, 마우스 선택·복사·붙여넣기, 색 테마 5종 + 글자/배경색, 내용 저장, 화면 지우기
- **경로 동기화** 4개 모드(양방향 / 탐색기→터미널 / 터미널→탐색기 / 끄기), 실행 중 명령이 있으면 보류
- 같은 데이터 폴더로는 앱이 하나만 실행됩니다(다시 실행하면 떠 있는 창이 앞으로 나옵니다)
- 다크/라이트 테마, 한국어/English, 글자 크기 설정, 설정·창 위치·마지막 경로 복원
- 제목 표시줄: 정보 창, 계산기, 휴지통 비우기, 시계. 하단: CPU/GPU/메모리 사용량

> 실행 시 **항상 관리자 권한**을 요청합니다(`app.manifest`). Windows x64용입니다.

## 사용 방법

### 시작
실행하면 준비되는 동안 작은 **"로딩 중..." 팝업**이 먼저 나타납니다. 계속 흐르는 진행 막대와 함께 "지금 무엇을 하는지"(`테마와 글꼴 적용 중...` → `폴더 크기 캐시 불러오는 중...` → `화면 구성 중...` → `터미널 시작 중...` → `준비 완료`)가 한 줄로 갱신되고, 메인 화면이 표시된 뒤 약 1초 후에 사라집니다. 팝업이 뜨기 전 잠깐(런타임 로딩 구간)은 화면에 아무것도 보이지 않을 수 있습니다.

### 화면 구성
```
[제목 표시줄]  로고(정보) · 버전  ……  시계  계산기  휴지통  설정  테마
[즐겨찾기 1~10]                                         경로 동기화 [양방향 ▾]
[◀][▶][▲][⟳]  [ 주소 표시줄 ───────────────────────────────── ]
[드라이브] [조부모 폴더] [부모 폴더] [현재 폴더: 이름/수정일/크기/하위 항목]
──────────────── 분할 막대(위아래로 끌어 높이 조절) ────────────────
[터미널]
[하단 상태 표시줄: 동기화 요약 · CPU · GPU · 메모리]
```

### 1. 즐겨찾기
- **빈 칸(`+ 등록`)을 클릭**하면 지금 보고 있는 폴더가 그 칸에 등록됩니다. 등록된 칸을 클릭하면 그 폴더로 이동합니다.
- **우클릭 메뉴**: 현재 폴더를 이 칸에 등록 · 이름 바꾸기 · 왼쪽/오른쪽으로 이동 · 이 칸 비우기.
- 칸은 최대 10개입니다. 설정 창의 "즐겨찾기 초기화"로 모두 비울 수 있습니다.

### 2. 탐색기
- **이동**: 주소 표시줄에 경로를 입력하고 Enter, `◀ ▶ ▲ ⟳` 버튼(뒤로/앞으로/위로/새로 고침), 드라이브 클릭(해당 드라이브 루트로),
  조부모/부모 열의 폴더 클릭, 현재 폴더 목록에서 폴더를 선택하고 Enter(또는 더블클릭). 없는 경로를 입력하면 오류가 표시되고 입력한 글자는 그대로 남아 고쳐 쓸 수 있습니다.
- **파일 열기**: 파일에서 Enter/더블클릭 → exe/cmd는 실행, 그 밖의 파일은 Windows 기본 프로그램으로 열립니다(작업 폴더는 그 파일이 있는 폴더).
- **정렬**: 이름/수정한 날짜/크기 머리글을 클릭하면 정렬, 다시 클릭하면 오름↔내림(▲▼). 폴더가 항상 먼저 나옵니다.
- **폴더 크기**: 폴더의 전체 크기와 "파일 N · 폴더 M"이 백그라운드로 채워집니다. 큰 폴더는 5 GB / 1천개 이상이면 "이상"으로 표시하고 계산을 멈춥니다.
  결과는 30분 동안 캐시되며, 새로 고침 버튼은 캐시를 무시하고 다시 계산합니다.
- **이름 검색**: 현재 폴더 열 머리글의 검색 입력칸(Ctrl+F)에 입력하면 이름으로 걸러지고 일치 개수가 표시됩니다. Esc로 해제합니다.
- **미리보기**: 이미지(png/jpg/gif/bmp/ico/tif/webp)는 썸네일, PDF는 첫 쪽, 텍스트/소스 파일은 앞 20줄을 툴팁으로 보여줍니다.
- **새로 고침 버튼**: 현재 폴더 머리글의 이름 검색 입력칸 앞에 있는 **녹색** 버튼으로 F5와 같습니다(폴더 크기도 다시 계산).
- **경로 복사 버튼**: 주소 표시줄 맨 오른쪽의 **주황색** 버튼으로 현재 경로를 클립보드에 복사합니다(복사되면 아이콘이 잠깐 체크로 바뀜).
- **숨김 파일**: 기본은 숨김·시스템 항목을 감춥니다. Ctrl+H(또는 우클릭 메뉴)로 보이게 하면 `.git`, `.vs` 같은 폴더가 흐리게 나타나고, 설정은 다음 실행에도 유지됩니다.
- **복사/이동 진행 표시**: 큰 파일·폴더를 붙여넣거나 끌어 놓을 때 0.3초 넘게 걸리면 목록 아래에 진행 막대(복사한 크기/전체, %)와 **취소** 버튼이 나옵니다. 취소하면 이미 끝난 항목은 남고 복사 중이던 항목의 반쪽 결과는 지워집니다.
- **끌어 놓기**: 목록의 항목(여러 개 선택 가능)을 폴더 행·상위 열의 폴더 위에 놓으면 이동합니다(Ctrl을 누르고 놓으면 복사, 다른 드라이브로 놓으면 기본이 복사, Shift를 누르면 이동). **터미널에 놓으면 경로가 입력줄에 입력**됩니다. 앱이 관리자 권한이라 Windows가 일반 권한 프로그램(탐색기 등)과의 끌어 놓기를 막으므로, 앱 안에서만 동작합니다.
- **우클릭 메뉴**: 복사·잘라내기·붙여넣기·이름 변경·삭제·새 폴더 외에 열기, 연결 프로그램 선택, 탐색기에서 보기, 경로 복사, 터미널에 경로 입력, 속성, 숨김 파일 표시가 있습니다.

| 키(파일 목록에 포커스가 있을 때) | 동작 |
|---|---|
| Enter | 폴더 열기 / 파일 실행 |
| Backspace | 위 폴더로 |
| F5 | 새로 고침 |
| F2 | 이름 변경 |
| Delete | 삭제(확인 후 **휴지통**으로 보냄, 영구 삭제 아님) |
| Ctrl+Shift+N | 새 폴더 |
| Ctrl+C / Ctrl+X / Ctrl+V | 복사 / 잘라내기 / 붙여넣기 (Windows 탐색기와 클립보드 호환, 이름이 겹치면 "- 복사"가 붙음) |
| Ctrl+F | 이름 검색 |
| Ctrl+H | 숨김/시스템 파일 표시 켜기·끄기(설정에 저장, 숨김 항목은 흐리게 표시) |
| Ctrl+Shift+C | 선택한 항목의 **전체 경로 복사**(여러 개면 줄마다 하나, 선택이 없으면 현재 폴더) |
| Ctrl+Shift+V | 선택한 항목의 경로를 **터미널 입력줄에 입력**(Enter는 누르지 않음, 공백·특수문자가 있으면 셸에 맞게 따옴표) |
| Alt+Enter | 속성 창 |

| 키(어디서나) | 동작 |
|---|---|
| Ctrl+Shift+T / Ctrl+Shift+W | 터미널 새 탭 / 현재 탭 닫기 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 터미널 탭 |

우클릭 메뉴에도 같은 항목이 있습니다. 삭제는 네트워크/이동식 드라이브처럼 휴지통이 없는 곳에서는 바로 영구 삭제됩니다.

### 3. 터미널
- 아래쪽 터미널에서 PowerShell(기본) 또는 명령 프롬프트를 사용합니다. 셸은 **설정 → 터미널 셸**에서 바꾸며, 바꾸면 터미널이 즉시 다시 시작됩니다.
- **탭**: 터미널 위쪽 탭 줄의 `+`(또는 Ctrl+Shift+T)로 새 탭을 엽니다(최대 8개). 새 탭은 탐색기의 현재 폴더에서, 설정의 셸로 시작합니다.
  탭마다 독립된 셸이며 제목은 "셸 · 현재 폴더 이름"입니다. 탭을 클릭하거나 Ctrl+Tab / Ctrl+Shift+Tab으로 전환하고, `×`(또는 Ctrl+Shift+W)로 닫습니다(마지막 탭은 닫을 수 없고, 명령이 실행 중인 탭은 확인 후 닫습니다).
  **경로 동기화는 선택된 탭만** 따릅니다. 탭을 바꾸면 탐색기가 그 탭의 폴더로 이동합니다(모드가 허용할 때). 설정에서 셸을 바꾸면 선택된 탭이 새 셸로 다시 시작되고 이후 새 탭도 그 셸을 씁니다. 탭은 앱을 껐다 켜면 하나로 돌아갑니다(저장되지 않음).
- **선택/복사**: 마우스 드래그로 글자를 선택(더블클릭은 단어). Ctrl+C는 선택이 있으면 복사, 없으면 실행 중단입니다. Ctrl+Shift+C는 항상 복사.
- **붙여넣기**: Ctrl+V. 우클릭은 선택이 있으면 복사, 없으면 붙여넣기입니다. 줄바꿈이 있으면(끝의 줄바꿈 하나뿐인 한 줄도) 실행 전에 내용을 보여 주고 확인합니다.
- **머리글 버튼**: `?` 사용법 · 지우기(스크롤백 포함) · 저장(전체 내용을 파일로) · 접기/펼치기. 마우스 휠로 지난 출력을 볼 수 있습니다.
- 한계: vim/less 같은 풀스크린 프로그램, 터미널 앱으로의 마우스 입력 전달은 아직 제대로 지원하지 않습니다.

### 4. 경로 동기화
오른쪽 위 **경로 동기화** 콤보에서 언제든 모드를 바꿉니다(설정은 저장됩니다).

| 모드 | 탐색기에서 이동하면 | 터미널에서 `cd` 하면 |
|---|:---:|:---:|
| **양방향** (기본) | 터미널도 이동 | 탐색기도 이동 |
| 탐색기 → 터미널 | 터미널도 이동 | 탐색기는 그대로 |
| 터미널 → 탐색기 | 터미널은 그대로 | 탐색기도 이동 |
| 끄기 | 그대로 | 그대로 |

터미널에서 명령이 **실행 중이면** 이동 요청을 잠시 보류했다가 프롬프트가 다시 나오면 반영합니다(알림 막대에 "대기 중" 표시).
프롬프트에 글자를 입력하던 중에 탐색기에서 이동하면 입력 줄 뒤에 `cd`가 붙을 수 있습니다.

### 5. 제목 표시줄과 설정
- **로고**: 정보 창(버전·환경 요약, 정보 복사, 로그 폴더 열기).
- **계산기**(Ctrl+Alt+C): Windows 계산기를 엽니다(이미 떠 있으면 앞으로 가져옵니다).
- **휴지통 비우기**(Ctrl+Alt+E): 항목 수/용량을 확인한 뒤 비웁니다.
- **테마 버튼**: 다크 ↔ 라이트 전환(저장됨).
- **설정**: 언어(한국어/English, 즉시 반영) · 글자 크기(화면/터미널) · 시작 시 마지막 폴더에서 열지 여부 · 터미널 색 테마와 글자/배경색(`#RRGGBB`) · 터미널 셸 · 즐겨찾기 초기화.
- 하단 상태 표시줄에 CPU / GPU / 메모리 사용량이 2초마다 표시됩니다(GPU 카운터가 없는 PC는 N/A).

- **종료**: 터미널에서 실행 중인 명령이 있으면 창을 닫을 때 확인합니다(종료하면 그 작업이 모두 끝나므로). 아니오를 누르면 계속 실행됩니다.

### 6. 설정/로그 파일 위치
- 설정: `%APPDATA%\PathDock\settings.json`, 폴더 크기 캐시: `%APPDATA%\PathDock\folder-size-cache.json`
- 로그: `%APPDATA%\PathDock\logs\pathdock-yyyyMMdd.log` (정보 창의 "로그 폴더 열기"로도 열 수 있음)
